## Как оно работает (пайплайн)

```
Диаризация (Deepgram Word.speaker, РАБОТАЕТ на видео: 2 спикера, 37 реплик за 10 мин)
  → build_turns: слова → реплики (турны)
  → ASD (Light-ASD @25fps, per-frame) на лица
  → build_seats: осколки IOU-трекера склеены в 2 «места» по позиции (лево/право)
  → bind_lanes: кластер-спикер ↔ место, голосованием per-turn ASD (baseline-норм + вес по n_words)
  → plan_switches: greedy scheduler cut'ов (min-hold + hysteresis + IoU-гейт + wide-фолбэк)
  → рендер: регионы → hard-cut (существующий stage5), Δ=0
```

## Три находки на РЕАЛЬНОМ видео (systematic-debugging — юнит-тесты их поймать НЕ могли)

Планировщик заработал сразу; трудным оказался **сигнальный слой** (детекция + атрибуция «кто говорит»):

1. **IOU-трекер дробит каждого человека на ~15 коротких треков** за 60с (ни один не набирает
   покрытия) → `build_seats` кластеризует осколки по cx в 2 «места» (замена ArcFace-reID для
   локированной камеры), гэп-кадры = сентинель `NO_ASD`, гейт по РЕАЛЬНОМУ покрытию.
2. **MediaPipe BlazeFace фронтально-смещён** → теряет наклонённые/профильные лица (мужчина смотрел
   вниз → детектился 12% кадров на conf 0.5). `det_conf=0.25` → 98%. Кноб `switch_det_conf=0.25`
   для speaker-режима (обычный путь остаётся 0.5).
3. **Lip-ASD ПОЗА-смещён на интервью лицом-к-лицу**: когда человек говорит, он смотрит на собеседника
   → профиль → ASD меряет фронтальность лица, не речь → более фронтальное лицо ВСЕГДА выше по
   абсолюту (женщина «выигрывала» все 7 реплик). Фикс в `bind_lanes`: (а) вычитаем СОБСТВЕННЫЙ базлайн
   места (сигнал речи = отклонение ВВЕРХ от базлайна); (б) вес голоса = `n_words` реплики (короткое
   «да» не перевешивает 50-словный ответ). Вместе → 6/7 верных реплик + верная биекция.

## Доказательство (глазами)

Окно [1140,1200], 4+ смены говорящего:
- BINDING `{s0(муж)→seat0 ЛЕВО, s1(жен)→seat1 ПРАВО}` (верно).
- 7 fill-регионов ровно по таймлайну реплик (муж 20с ответ → tight ЛЕВО; жен 22с → tight ПРАВО; …).
- Кадры: `r02_fill_mid` = мужчина крупно (говорит), `r05_fill_mid` = женщина крупно, `r03_fill_cut+00`
  = чистый cut на женщину на онсете её реплики. Фоны у ЛЕВО/ПРАВО кропов РАЗНЫЕ (стена vs окно) →
  cut читается как ДВЕ камеры, не «фотку подвинули».
- GRID Δ = 0.000000.
