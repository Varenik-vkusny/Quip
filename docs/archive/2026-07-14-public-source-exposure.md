# 2026-07-14 — ⚠️ ОТКРЫТАЯ ЗАДАЧА: сырой source.mp4 публичен на CDN

> Найдено при починке бага с TTL медиа-тикета. НЕ регрессия (публичный бакет древний). Основатель
> решил: **зафиксировать и разобрать отдельно** (не срочно). Эта записка — чтобы не потерялось.

## Факт (проверено на бою)

```
curl https://cdn.quip.ink/{job_id}/source.mp4    → HTTP 200, 9.2 ГБ, БЕЗ авторизации
curl https://cdn.quip.ink/{job_id}/preview.mp4   → HTTP 206, 166 МБ, БЕЗ авторизации
```

Сырой исходник пользователя (его загруженное видео) и preview-прокси **отдаются CDN публично** любому,
кто знает `job_id`. Клипы тоже публичны — но это ВЫХОД, который юзер и так хочет расшарить; а source —
это приватный ВХОД (может быть неопубликованный подкаст, черновик и т.п.).

## Почему так

`storage._r2_read_url` (`storage.py:604`) при заданном `R2_PUBLIC_URL=cdn.quip.ink` возвращает
публичный CDN-URL для ЛЮБОГО ключа, включая `{job}/source.mp4` и `{job}/preview.mp4`. Бакет R2
публичный (клипы на нём и держатся). То есть HMAC-тикет (`media_token.py`) защищает только шаг
302-редиректа на API, но **сам объект на CDN не тикет-защищён**. Комментарий `storage.py:168`
(«source приватный») противоречит реальности.

## Насколько открыто

`job_id = uuid4().hex[:12]` = **48 бит** (`main.py:423`). Брутом не перебирается, но УТЕКАЕТ:
- в URL расшаренного дашборда `quip.ink/dashboard?job=job_xxx`;
- в access-логах и заголовке `Referer`;
- в теле медиа-тикета (base64, читается за секунду);
- в наших собственных логах.
Ретеншн удаляет source/preview через 60 дней (`storage.py:675-721`) — окно ограничено.

## Чинить осторожно (почему это НЕ однострочник)

Наивное «залочить бакет» СЛОМАЕТ скачивание клипов — оно ОПИРАЕТСЯ на публичность клипов на CDN
(bulk-download 2026-07-14 качает `cdn.quip.ink/{job}/{clip}_captioned.mp4` напрямую). Значит нужно
РАЗДЕЛИТЬ:
- клипы (`{clip}.mp4`, `{clip}_captioned.mp4`) — остаются публичными (это фича);
- source/preview (`source.mp4`, `preview.mp4`) — приватные.

Варианты (нужна спека перед реализацией):
1. **Cloudflare/R2 rule**: заблокировать публичный доступ к ключам `*/source.mp4` и `*/preview.mp4`
   (по суффиксу), оставив клипы. Тогда `/preview.mp4?mt=` должен отдавать НЕ 302-на-CDN, а
   presigned-URL или проксировать (⚠️ проксирование через api-контейнер = OOM, см. инцидент —
   значит presigned).
2. **Отдельный приватный бакет/префикс** для source/preview, `R2_PUBLIC_URL` только для клипов.
3. Смириться (job_id как capability-token) — но тогда честно убрать тикет-театр и написать это в доке.

Затрагивает: `storage.py` (`_r2_read_url`/`source_read_url`/`preview_read_url`), `main.py`
(`/preview.mp4`, `/source.mp4`), Cloudflare/R2-конфиг (`deploy/modal/r2_setup.py` перечисляет
CORS/бакет), и НЕ должно задеть публичность клипов (проверить bulk-download E2E после).
